# Language Soulmate - KOL 🤝

**Language Soulmate** is a mobile application designed to bridge the gap between Israelis and Palestinians through language learning and shared interests.

## 🚀 The Concept
Instead of random matching, users are connected based on:
1.  **Language Goals:** Native Hebrew speakers learning Arabic & Native Arabic speakers learning Hebrew.
2.  **Personality:** Shared hobbies (Surfing, Coding, Music) and interests.
3.  **Location:** Connecting neighbors from different communities.

## 📱 Features (Milestone 1-4 Implementation)
* **Smart Matching Logic:** Algorithm that cycles through potential partners.
* **Profile Cards:** Displays name, location, languages, and hobbies.
* **Interaction:** "Pass" or "Connect" buttons with instant feedback.
* **Mock Data Integration:** Realistic user profiles simulation.

## 🛠 Tech Stack
* **Frontend:** React Native (Expo)
* **Language:** JavaScript (ES6+)
* **Styling:** StyleSheet API

## 🏃‍♂️ How to Run
1.  Clone the repository.
2.  Run `npm install` to install dependencies.
3.  Run `npx expo start` to launch the app.
4.  Scan the QR code with the **Expo Go** app on your phone.
